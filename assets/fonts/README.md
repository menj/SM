# Bundled fonts

| Family | Role | Files |
| --- | --- | --- |
| Sabon Next LT | Editorial serif: headlines, navigation, quotes | `sabon-next/` (Regular, Italic, Bold, Bold Italic) |
| Kagnue | Display: site title, section and page headings | `kagnue/` (Regular, Outline) |
| Special Elite | Press labels: tags, dates, bylines, footer | `special-elite/` |
| Ferments | Script accent: donate visual, quote credits | `ferments/` (Regular, Slant) |

Converted from the supplied TTF files to WOFF2. Licences:

- **Special Elite**: Apache License 2.0 (Astigmatic). Free to bundle.
- **Sabon Next LT**: Copyright Monotype GmbH. Commercial. A web font licence is required before serving it on a public site.
- **Kagnue**: Youthlabs Studio. The file's embedding flag allows preview and print only. Confirm the licence allows web use.
- **Ferments**: Haksen Studio, all rights reserved. Confirm the licence allows web use.

Keep proof of purchase with the project. To swap a font, replace the file and update the matching entry in `theme.json`.
