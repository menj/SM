# Bundled fonts

| Family | Role | Files |
| --- | --- | --- |
| Sabon Next LT | Editorial serif: headlines, navigation, quotes | `sabon-next/` (Regular, Italic, Bold, Bold Italic) |
| Kagnue | Display: site title, section and page headings | `kagnue/` (Regular) |
| Special Elite | Press labels: tags, dates, bylines, footer | `special-elite/` |
| Ferments | Script accent: donate visual, quote credits | `ferments/` (Regular, Slant) |
| Dropcaps | Illuminated initials for article openings | `dropcaps/` (SIL OFL, letter outlines derived from Almendra) |

Converted from the supplied TTF files to WOFF2. Licences:

- **Special Elite**: Apache License 2.0 (Astigmatic). Free to bundle.
- **Dropcaps**: SIL Open Font License (letter outlines derived from Almendra). Licence file included.
- **Sabon Next LT** (Monotype), **Kagnue** (Youthlabs Studio) and **Ferments** (Haksen Studio): web licences held by the site owner. Keep the proof of purchase with the project.

To swap a font, replace the file and update the matching entry in `theme.json`.
